## 4. 直したこと: `net` の初期値つきデータ
`net` のイメージが 351 KB あり、ストアの中で一番大きかった。

- 原因: 空の値が 0 のバイト列でない静的変数は、初期値つきの領域（.data）に入り、イメージに含まれる。該当したのは次のもので、合わせて約 107 KiB。

  | 静的変数 | 大きさ |
  |---|---|
  | フィルタの接続の表 | 52 KiB |
  | UDP のメタデータ | 22 KiB |
  | Ethernet のソケットの置き場 | 15 KiB |
  | NAT の表 | 12 KiB |
  | インタフェース 0 のソケットの置き場 | 6 KiB |
- 対処: これらを `MaybeUninit` で .bss に置き、`net` の起動時（`init_statics`、`filter::init`、`nat::init`）にその場で空の値を書き込むようにした。52 KiB の表をスタック上で組み立てないよう、要素ごとに書く。
- 結果: .data は 123,800 B から 15,192 B に、イメージは 351 KB から 243 KB に減った。t5emu の試験一式と、実機の DHCP、NAT、DNS、HTTP、NDP proxy は以前どおり動く。

## 5. 測れていないもの
- **CPU 使用率**: doc/31 で `ps` に出すようにした。
- 負荷をかけたときの値（大きな転送の最中の CPU、キューの溢れ）。
- プロセスの数の上限は 4（`MAX_PROCS`）。`wifi`、`net`、`fs` に試験のアプリを 1 つ足すと埋まる。試験中に「no free slot」が一度出た。
