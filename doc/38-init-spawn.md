# 38. 起動するアプリを SD のファイルで決める（`init` と `proc:spawn`）

利用者の選択（2026-11-02）: 「init プロセス」案。ほかの案は、カーネルがフラッシュに表を持つ案と、後回しにする案だった。doc/30 §6 の「自動起動の設定を SD のファイルで」に当たる。

## 1. 前の形と問題
- カーネルは、ストアの中で自動起動の印の付いたアプリを起動時に動かす（doc/30 §5）。どれを起動するかを変えるには、印の付いた版か付いていない版を入れ直すしかなかった。
- SD のファイルを読むのはユーザーモードの `fs` サービスで、カーネルは FAT を読めない。また、アプリから別のアプリを起動する手段がなかった（起動できるのはカーネルとデバッグのコンソールだけ）。

## 2. 形（ABI 小版 14）
- **カーネルのオブジェクト `proc:spawn`**（`t5_abi::spawn`）。開くにはイメージの許可（`--permit proc:spawn`）が要る。権利は WRITE だけ。
  - `write` に `[arg0: u32 LE][arg1: u32 LE][名前]` を書くと、ストアのアプリ `名前` をその引数で起動するよう頼める。名前は 1〜32 バイトの UTF-8 で、それ以外は `Size` か `Invalid`。
  - 頼みは待ち行列（8 個）に入り、`write` はそこで戻る。満杯なら `Busy`。
  - カーネルのサービスのループ（`POLL_MS` = 10 ms ごと）が、頼まれた順に起動する。結果はイベントで知らせる: `proc.spawned`（頼んだ pid、名前、新しい pid）、`proc.spawn_failed`（名前、理由）。
  - **待ち行列にした理由**: システムコールは、スケジューラが呼び手のプロセスを持ったまま処理する。その中でスケジューラとストアを触れないので、サービスのループに渡す（`settle_updates` と同じ場所）。
- **権限**: 起動したアプリは、自分のイメージの許可だけを持つ。頼んだプロセスの権限は受け継がない。なので、`proc:spawn` で権限は上がらない。できるのは、ストアにある署名済みのアプリをどれでも起動することと、プロセスの枠（8）を使い切ること（判断: 許可を持つアプリだけに限れば十分）。
- **アプリ `init`**（`--permit proc:spawn --permit svc:fs`）:
  - mode 0（起動時）: `svc:fs` に最大 10 秒つなぎ、SD の `T5OS/START.CFG` を読み、各行のアプリを頼む。ファイルが読めなければ、組み込みの表（`wifi`、`net`、`netctl`）を使う。SD を抜いても、ネットワークは上がる。
  - mode 1: 組み込みの表を `T5OS/START.CFG` に書く（書き換えの出発点）。
  - mode 2（t5emu の試験）: `hello` と、ストアにない名前を頼む。その後、33 バイトの名前をカーネルが `Size` で断ることを確かめる。
  - 行の形は `NAME [ARG0 [ARG1]]`（10 進か 0x の 16 進）。`#` から後は注釈。読めない行は `init.bad_line` を出して飛ばす。自分（`init`）の名前は飛ばす。
- **自動起動の印**は `fs` と `init` だけにした（Makefile の `AUTO_APPS`）。`wifi`、`net`、`netctl` は印なしで入れ、`init` が起動する。

## 3. 試験
- `make test-p4emu` に、`run init 2` の場合を足した。`proc.spawned`、`hello.greet`、`proc.spawn_failed`、`init.done` を待つ。
- 許可のないアプリが `proc:spawn` を開けないことは、他の名前と同じ仕組み（`t5a::permits`）による。自己試験の `fault/open-denied` で確かめている。
- 実機（2026-11-02）: カーネル（ota_seq=56）を入れ、`make install-apps` で `fs` と `init` を印つき、`wifi`/`net`/`netctl` を印なしで入れ直した。`run init 1` で `T5OS/START.CFG` を書き、再起動した:

  | 時刻 | できごと |
  |---|---|
  | 2.6 秒 | 自己試験が通り、`fs` と `init` が起動 |
  | 2.82 秒 | `init` が `START.CFG`（91 バイト）を読み、3 つを頼む |
  | 2.86〜3.13 秒 | `proc.spawned`: `wifi`、`net`、`netctl` |
  | 3.28 秒 | `netctl` が SD の規則 4 つを入れて終了（0） |
  | 26.4 秒 | Wi-Fi の DHCP |

## 4. 使い方
- 起動するアプリを変えるには、SD の `T5OS/START.CFG` を書き換える。PC で書いても、`run init 1` で書き直してもよい。
- 自動起動の印は、`fs` と `init` 以外には付けない。印のあるアプリは、カーネルと `init` の両方から起動されてしまう。
