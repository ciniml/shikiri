# 62. term の履歴（ページング）と shell の入力補完

利用者の指示（2026-11-08）:「あとtermでページングとか、入力補完」

## 1. term の履歴（スクロールバック）
- 主画面の上から押し出された行を 200 行まで取っておく（`vt::HISTORY`、輪。1 行 80 セル × 24 バイトで約 375 KB、`.bss`）。スクロール領域の上端が画面の上端のときだけ（`vim` などの範囲付きのスクロールや代替画面の行は入れない）。
- **Shift+PgUp / Shift+PgDn** で 20 行（`ROWS` − 2）ずつ戻る・進む。キーは端末が受け、`shell` には送らない。押し続ければ繰り返す。
- 戻っている間は、右上に `[-戻った行/全部]` を反転で出し、カーソルは出さない。ほかのキー（文字、Enter など）を押すと、今の画面に戻ってからそのキーを送る。戻っている間に出力が来ても、見ている行はそのまま（ずれない）。
- 代替画面（全画面のアプリ）では戻れない。`ESC [ 3 J`（xterm の「保存した行を消す」）で履歴を消す。
- 描き方は今までと同じで、見えるべきセルと表示中のセルを比べるので、戻る・進むも 2D の写し（doc/44）で画面を動かす。
- `term.view`（back、lines）を記録する。

## 2. shell の Tab 補完
- 行の末尾の単語を補完する（`shell` の行編集は末尾にしか書かないので、それで足りる）。
  - 1 つ目の単語: コマンド（`help` の一覧）。
  - `run` の後: ストアのアプリ（`proc:apps`）。
  - `fg` の後: 動いているプロセスの名前（`proc:list`）。
  - `cfg` の後: `list`、`get`、`set`、`secret`、`rm`。
  - `ls`、`cat`、`more`、`write`、`rm`、`mkdir` の後: SD のファイル（`fs` の LIST）。`/` までのディレクトリはそのまま、その先の名前を大文字小文字を区別せずに比べ、ファイルの表記で置き換える。ディレクトリは `/`、ほかは空白で閉じる。
- 候補が 1 つならそれで閉じる。複数なら共通の頭まで伸ばし、伸びなければ候補を並べて（80 桁で折り返す、48 個まで、超えたら `...`）プロンプトと行を出し直す。

## 3. shell の more
- `more FILE`: 21 行ずつ（80 桁で折り返して数える）。`--More--` で、空白は次の画面、Enter は 1 行、q（ほかのキー）でやめる。

## 4. 試験
- p4emu-run-32: `upt<Tab>` で `uptime` が動き、`fg ter<Tab>` が `fg term` になる（`shell.fg`）。`help` の後に Shift+PgUp（エミュレータの `keys` の `<pgup>`）で 12 行戻り（`term.view back=12 lines=12`）、写しの右上に反転の表示（背景ではなく前景の色）。
- エミュレータの `keys` に `\t`（Tab）、`<pgup>`、`<pgdn>` を足した。
- `more` とファイル名の補完は SD が要り、エミュレータでは試していない（実機で）。
