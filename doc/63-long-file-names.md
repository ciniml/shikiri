# 63. 長いファイル名（VFAT LFN）

利用者の指示（2026-11-08）:「ファイルシステムが短い名前しか扱えないのは対応可能ですか？」→ 段取りは「読むのを先に、作るのは次に」（利用者の選択）。

## 1. これまで
- `fs` は embedded-sdmmc 0.10 の 8.3 名だけを使っていた。PC で作った長い名前のファイルは、`ls` で `LONGFI~1.TXT` のような別名でしか見えず、長い名前では開けなかった。
- embedded-sdmmc 0.10 は長い名前を**読める**（`iterate_dir_lfn`、`open_long_name_file_in_dir`）が、**作れない**（新しいファイル・ディレクトリ・名前の変更）。

## 2. 段 1（済み）: 今ある長い名前を使う
- **名前の引き方**: パスの各部分を、そのディレクトリの長い名前か 8.3 名と、ASCII の大文字小文字を区別せずに比べ（`Service::lookup`）、見つかった項目の 8.3 名で embedded-sdmmc を呼ぶ。開く、読む、書く（今あるファイル）、ディレクトリをたどる、消すが、長い名前でできる。
- **見つからない名前**: 段 2 で、長い名前として作れるようになった（§3）。
- **一覧**: 新しい要求 `LIST_LONG`（9）。1 項目 128 バイト（名前 120 バイトまで、UTF-8、文字の境目で切る、長い名前がなければ 8.3 名、大きさ、属性）。ボリュームラベルは出さない。`t5_rt::Files::list` は `LIST_LONG` を使い、古い `fs`（`BAD_REQUEST`）なら `LIST` に戻る。`shell` の `ls` と Tab 補完は、そのまま長い名前になる。
- **許可**（doc/52）: パスは今までどおり大文字にして比べる。長い名前も同じ（`svc:fs/r:PATH` の PATH は長い名前でも書ける）。
- **気をつけること**:
  - 空白を含む名前は `\ ` か `"..."` で打つ（doc/64 §4）。

## 3. 段 2（済み、2026-11-08）: 長い名前を作る、消す
- 「エミュレータでのSDの動作確認ができたら、書き込みの実装に進んでください」（利用者）。
- **embedded-sdmmc を手元に取り込んだ**（`third_party/embedded-sdmmc-0.10.0`、`user/Cargo.toml` の `[patch]`）。rust-fatfs に替えるより、`fs` の作りをそのままにでき、変更が小さい（rust-fatfs の LFN は未公開の 0.4 にしかない）。足したもの:
  - `VolumeManager::set_long_name(volume, name)`: 次に作る項目（`open_file_in_dir` の作成、`make_dir_in_dir`）に長い名前を付ける。`FatVolume::pending_lfn` に持ち、`write_new_directory_entry` が取る。
  - `write_new_directory_entry_lfn`: ディレクトリを先頭から見て、LFN の項目（13 字ずつ）＋ 8.3 の項目が入る空きの連なりを探し（足りなければクラスタを足す）、名前の後ろの部分から順に LFN の項目（チェックサム、終わりの 0x0000 と 0xFFFF の詰め、最後に 0x40）、最後に 8.3 の項目を書く。
  - `delete_directory_entry`: 8.3 の項目の直前の LFN の項目（同じチェックサム）も消す（孤児を残さない）。
  - 共通の `walk_dir_blocks`（ディレクトリのブロックを順に、FAT16 のルートは固定の範囲、ほかはクラスタの鎖）。
- **`fs`**:
  - パスの大文字小文字を保つ（`normalise` で大文字にしない）。許可（doc/52）の比べと名前の引き方は大文字小文字を区別しない。
  - 新しい名前が大文字の 8.3 名ならそのまま作り、そうでなければ（小文字、長い、空白、8.3 にない文字）長い名前として作る。別名は、大文字にしただけで済めばそれ（`new.txt` → `NEW.TXT`）、だめなら `BASE~N.EXT`（空白と点を落とし、使えない文字は `_`、空いている最初の N、999 まで）。
  - 長い名前のディレクトリも作れる（`mkdir "New Folder"`、自分のフォルダの作成も同じ道）。
  - 開くとき、ない名前で作成でなければ `NOT_FOUND`（前は長い名前だと `BAD_NAME`）。
- **まだ**: 名前の変更（`rename`）はない。FAT16 のルートの固定の大きさを超えると `FULL`。

## 4. 試験
- エミュレータの microSD（doc/64）で: p4emu-run-33。長い名前のフォルダとファイルを読み、長い名前のファイル 3 つ（同じ別名の頭で `NOTESF~1`、`NOTESF~2`）、小文字の 8.3 名（`new.txt` → 別名 `NEW.TXT`）、長い名前のフォルダとその中のファイル、大文字の 8.3 名を作り、長い名前のファイルを消す。走った後の像を mtools で読み（長い名前で中身、消したものはない）、`tools/fatcheck.py` ですべての LFN の項目が 8.3 の項目の直前に順に並び、チェックサムが合い、孤児がないことを確かめる。
- 実機（Tab5）でも、PC で長い名前のファイルを置いたカードで。
